# Screenshots

Drop PNGs here and they'll be picked up by `linux/README.md`.

Suggested set (names the README expects):

| File | What to capture |
|---|---|
| `panel.png` | the panel widget — the two coloured percentages with the companion |
| `popup-home.png` | popup Home tab — limits, companion, today/week/month |
| `popup-shop.png` | popup Shop tab |
| `popup-collection.png` | popup Collection tab — Pokédex grid or Catch log |
| `settings.png` | the settings dialog |
| `pet.png` | the floating desktop pet (optional) |

Crop tightly to the widget so no unrelated desktop content is published.
